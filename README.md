# 📱 Smart Parking Mobile Application

Android mobile application for the **Smart Parking System Graduation Project** using **Kotlin**, **Firebase**, and **Real-Time Parking Management**.

---

## 🚗 Overview

The Smart Parking Mobile Application is an Android application developed to provide users with an easy and efficient way to:

- Reserve parking slots
- Monitor parking availability in real time
- Manage reservations
- Simulate payments
- Improve parking security and automation

The application is part of a larger **IoT & AI-based Smart Parking System** powered by ESP32, Firebase, RFID, and AI license plate recognition.
